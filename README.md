# DRIVE GAME2（Rust 版）

MSX・FAN の読者投稿コーナー「ファンダム」に掲載されたゲーム「DRIVE GAME2」（作：HASEMAKO さん）を、誌面のプログラムリストから Rust で復元したものです。

当時の雰囲気を壊さないことを第一に、原作の MSX-BASIC を行番号ごとに追いかけて、画面・動き・音・速さを再現しています。

## 原作について

| 項目 | 内容 |
|---|---|
| タイトル | DRIVE GAME2（ドライブ・ゲーム・ツー） |
| 作者 | HASEMAKO |
| 掲載誌 | MSX・FAN（徳間書店インターメディア）読者投稿コーナー「ファンダム」 |
| 掲載号 | 1992年1月号（誌面の内容からの推定） |
| 対応機種 | MSX / MSX2 / MSX2+（RAM 16K） |
| 言語 | MSX-BASIC（行番号 10〜230 の短いプログラム） |

編集部の補足によると、もともと6画面ぶんあったプログラムを圧縮して投稿された作品です。

## ゲームの内容

道が画面の上から下へ流れていく、縦スクロールのドライブゲームです。
（誌面の「遊び方」ページは手元にないため、以下はプログラムの動きから読み取った内容です）

- 自車は左右だけでなく、画面の上下にも動きます。アクセルを踏んでいる間は少しずつ上へ進み、離すと下へ下がっていきます。
- 画面の上のほうを走るほど、走行距離が早く伸びます。
- 道の外（♦ の安全地帯）にはみ出すと、押し戻されて下がります。
- じゃま車にぶつかる、道の外の空白に突っ込む、画面の下へ落ちると「CRUSH」でゲームオーバーです。
- 走行距離が一定を超えると、道をふさぐクラスライン（E → D → C → B → A）が現れます。越えるたびにクラスが上がり、背景の色が変わり、じゃま車が増えます。
- クラス A のラインを越えるとクリア。クリアまでのタイムがハイスコア（初期値 3分0秒）より速ければ記録が更新されます。

## 遊び方

```
cargo run --release
```

| キー | 操作 |
|---|---|
| スペース（または Z） | アクセル（押している間だけ加速） |
| ← → | ハンドル（慣性つき。斜め入力では切れない） |
| Esc | 終了 |

Linux でビルドする場合は `libasound2-dev libx11-dev libxi-dev libgl1-mesa-dev` などが必要です。

## 再現の方針

- 画面は MSX の SCREEN 1（32×24文字 = 256×192ドット）を小さな VDP として持ち、原作と同じ作りで動かしています。
  - `ESC L`（1行挿入）で道を1行ずつ下へ流す
  - VRAM 上の文字を読み、文字ごとの表 `CH()` で当たり判定する
  - `ON CH() GOTO` の値が 0 のとき次の行へ進む動き（安全地帯と同じ処理になる）も原作どおり
- 車・道の縁・じゃま車の形、色テーブルの書き換え（道の白、縁の紫、12色のじゃま車、クラスごとの ♦ の色替え、クラッシュ時の点滅）は原作のデータどおりです。
- 音は MSX の PSG と PLAY 文（MML）をエミュレートして鳴らしています（`src/psg.rs`）。
  - エンジン音: `SOUND 0,Y` で車の高さにつれて音程が変わる
  - クラッシュ: ノイズとエンベロープの爆発音
  - スタート・クラッシュ・クリアの曲: テンポ、音長、エンベロープまで再現
- 速さは実機（Sony HB-F1XV の BIOS を使った openMSX）で測った値に合わせています。
  - メインループ 1周 約0.154秒（じゃま車を置いた周は約0.190秒）
  - `FOR I=0 TO 4500:NEXT` などの待ち時間、BEEP の長さ
- 乱数を整数変数に入れるときの切り捨てなど、MSX-BASIC の細かい挙動も実機で確かめて合わせています。
- 自車の下のほうが左右非対称なのも原作どおりです（`SPRITE$` の文字列に入っている「くくく」による）。

## 原作と違うところ

- 文字フォントは、このために描いたものです。MSX の ROM フォントは使っていません。
- クラスライン（64文字）を書く周の時間は実測していないため、見積もりです。
- BEEP の音色は近似です。

## 動作確認用の環境変数

- `DRIVE2_AUTOPLAY=1`: 自動で走る（`crash` にするとアクセルを踏まずにクラッシュする）
- `DRIVE2_SNAPSHOT=out DRIVE2_SNAPSHOT_AT=5,10`: 指定した秒数の画面を `out.0.rgba` などに保存して終了（256×192 RGBA）
